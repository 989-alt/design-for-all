파일은 저작물이라 저장소에 복사·커밋하지 않는다. 변환본은 세션 스크래치패드에만 있다.

**단원의 실제 주제는 '제품 디자인'이다.** 유니버설 디자인은 그 안의 한 요소("누구나 사용하기 편리")로 들어오고, '유니버설 디자인'이라는 용어 자체는 **교사용 배경지식에만** 있다(아래 ⑦·`미확보·불일치` 참조). 사용자 요청과 교과 범위의 이 차이를 PRD 에서 명시적으로 다룬다.

단원 목표 ① 제품 디자인에서 생각해야 할 요소를 이해하고 사례집을 만들 수 있다 ② 창의적인 발상으로 생활 속 제품을 목적에 맞게 디자인할 수 있다 ③ 제품 디자인 전람회를 계획하고 실행할 수 있다 [지도서 §단원개관]

중점 교과 역량: 심미적 감성(제품 디자인 탐색·미적 지각) · 창의·융합(불편 개선·아이디어 결합·기능성↑) · 공동체(모형 제작·전람회에서 타인 존중·협력) [지도서 §단원개관]

## 지도 내용

번호는 PRD 학습 매핑표의 키다. `★` = 지도서 평가 기준·확인하기에 직접 걸리는 핵심. `(참)` = 지도서 배경지식·참고 수준. `(선택)` = 지도서 선택 활동.

### A. 마음 열기 「어떤 화장실 쓸래?」 — 1차시 도입, 교과서 p.54 [6미01-03]

1. ★ **제품 디자인의 정의**: 생활에서 사용하는 제품의 **기능성을 높이고 아름답게** 만드는 것. 최근에는 **누구나 사용하기 편리하고 환경까지** 생각하며 디자인한다 [교과서 p.54][지도서 §마음열기 관련 개념]
2. ★ 두 화장실 그림을 비교해 다른 부분 찾기 → 마음에 드는 제품과 까닭 → 바꾸고 싶은 제품 디자인. 예시 답: 디지털 화면 거울(물 사용량이 보여 물 절약) / 자석 비누(일반 비누와 차이 없음 → 한 번 쓸 양이 나오는 비누면 좋겠다). **"제품을 사용하는 예시 상황"을 통해** 기능성·아름다움·누구나 편리·환경을 자연스럽게 인식 [교과서 p.54][지도서 §마음열기 지도 길잡이]
3. (선택) 우리 집 화장실 그리기: 디지털 기기로 화장실 제품 검색 → 원하는 요소를 생각해 바꾸고 싶은 화장실 그리기 → 왼쪽 화장실과 비교해 달라진 점 말하기 [지도서 §마음열기 ❷]

### B. 제품 디자인에서 생각해야 할 요소 — 1~3차시, 교과서 p.55 [6미02-01 지식·이해, 6미01-03]

4. ★ **제품 디자인의 요소 6**: ⑴ 목적에 맞음 ⑵ 최신성(첨단 기술) ⑶ 기능성 ⑷ 아름다움 ⑸ 사용하기 편리(누구나 사용) ⑹ 환경 고려 [지도서 §생각펼치기1 ❶ 예시 답, 마무리 ❶ "목적에 맞고 기능성, 편리성, 아름다움에 환경까지"]
5. ★ **사례 6점과 각 사례의 중점 요소** [교과서 p.55][지도서 §생각펼치기1 ❶, §작품]:
   - 뉴비(N사, 자율 주행 로봇, 2022) — 이동이 편리한 작은 크기, 혼자 다니게 눈 모양·카메라. **첨단 기술·편리**
   - 리쿠(T사, 2019) — 인공 지능·센서로 사람과 상호 작용, 얼굴 인식·인사·대화. 친구가 되어 주도록 사람 닮은 모습. **첨단 기술·친근감**
   - 시각 장애인을 위한 시계(E사, 2012) — 구슬을 만져 시간 확인, 자석 따라 구슬 이동. 앞면 구슬=분, 옆면 구슬=시. 더 자주 확인하는 '분'을 수월하게 보도록 고안. **"누구나 사용할 수 있다"** = 편리성
   - 병뚜껑으로 만든 치약 짜개(S사, 2022) — 지역에서 버려지는 플라스틱 뚜껑 수거·분쇄·압출. 자원 순환 업사이클링. **환경**
   - 방수포로 만든 가방(F사, 2020) — 폐방수포·폐현수막·폐안전벨트·자전거 튜브·구명조끼 업사이클링. **환경**
   - 프루스트 의자: 지오메트리카(멘디니, 2009) — 평범한 의자 형태 + 추상적·독특한 현대 패턴. 포스트모던 대표작. **아름다움**
6. ★ 사례를 보고 "어떤 부분을 중점으로 디자인했는가" 말하기, 시각 장애인 시계는 "어떻게 사용해야 할지" 생각하기, 환경을 생각한 제품을 더 말하기(페인트 통 화분, 재활용 플라스틱 열쇠고리), 인상 깊게 본 제품 말하기(젖는 면이 안쪽으로 접히는 우산) [지도서 §생각펼치기1 동기유발·❶]
7. ★ **모두를 위한 디자인 = 유니버설 디자인(Universal Design)**. 좋은 예: **저상 버스** — 휠체어가 탈 수 있도록 차체를 최대한 낮추고 계단을 없앰 → 휠체어 이용자뿐 아니라 계단 오르내리기 힘든 **노인·관절염 환자에게도 똑같은 편의** [지도서 §배경지식 "모두를 위한 디자인"]. **교과서 본문에는 용어가 없고** "누구나 사용하기 편리"(①)와 시각 장애인 시계 사례(⑤)로만 드러난다 [교과서 p.54~55]
8. (참) 디자인 어원: designare(계획을 기호로 명시하다) / de+sign(형상을 이탈하다 → 기존 틀을 탈피해 새 아이디어). 디자인 3영역: 제품·시각·환경. 제품 디자인 = 심미성과 인간적 가치, 실용성·아름다움·개성·재료 고려, 대량 생산 제품의 외형적 특질 결정 [지도서 §배경지식]
9. (참) 디자인 요소 — 내용적(목적·용도·기능·의미) / 형식적(형태·색·질감, +빛·운동·공간·시간). 디자인 원리 — 조화(통일)·균형·율동. **디자인 조건 4** — 합목적성(기능성·실용성)·심미성·경제성·독창성 [지도서 §배경지식]
10. ★ **제품 디자인 사례집 만들기**: 디지털 기기로 여러 제품 디자인 조사 → 좋은 디자인 제품 고르기 → **주제를 정해 분류**(교과서 예: 장소별 — 학교에서 쓰는 제품 / 놀이터에서 볼 수 있는 제품 / 내 방에 두고 싶은 제품) → 디지털 기기로 사례집 제작. 선택한 제품들과 **어울리는 형과 색으로 사례집 틀** 구성 [교과서 p.55][지도서 §생각펼치기1 ❷·유의점]
11. 사례집 중 소개하고 싶은 제품 발표(예: 퍼즐 책상 — 일부를 뜯어 쓰고 더 붙여 쓰는 다양성). 온라인: 학급 소통방 업로드 + 소개 글, 친구 사례집에 댓글 [지도서 §생각펼치기1 ❸, §디지털 매체 활용 길잡이]
12. (선택) 내가 다니고 싶은 학교 공간 만들기: 바꾸고 싶은 학교 공간 정하기 → 디지털 기기로 꾸밀 제품 디자인 찾기 → 참고해 그리기 [지도서 §생각펼치기1 선택]

### C. 제품 디자인 전람회 열기 — 4~6차시, 교과서 p.56~57, 프로젝트 학습법 [6미02-01, 6미02-04, 6미03-03, 6미03-04]

13. ★ **디자인 과정 5단계**: 문제점 찾기 → 조사하기 → 설계하기 → 모형 제작하기 → 전람회 열기 [교과서 p.56~57]. 지도서 배경지식의 디자인 프로세스 6단계: 디자인 목적 인식 → 아이디어 확장 → 표현 가능성 탐색 → 아이디어 구체화 → 디자인 창작 → 디자인 평가 [지도서 §배경지식]
14. ★ **문제점 찾기** — 생활용품을 사용하며 불편했던 점. 교과서 예: 학교 책상 **수납공간 부족**, 모둠 활동 때 **책상 옮기기 번거로움**. 사용자마다 다른 불편: 의자가 너무 딱딱 / 키 큰 나에겐 책상이 낮음 / 팔을 다쳐서 책상 옮기기 힘듦 [교과서 p.56~57][지도서 §생각펼치기2 ❶]. 느린 학습자용: 주변 제품의 불편함을 다룬 기사 제공 [지도서 §생각펼치기2 지도 길잡이]
15. ★ **조사하기** — 디자인할 제품을 정하고 비슷한 제품 조사 4갈래: 최근 인기 디자인(의자 일체형 책상, 오래 앉아도 안 피로한 의자) / 독창적 가구(쿠션 두 개 붙인 의자) / 이동이 편리한 제품(부피 작게, 다리에 바퀴) / 적용할 첨단 기술(책상 윗면 디지털 화면) [교과서 p.56][지도서 §생각펼치기2 ❷]
16. ★ **설계하기** — 문제점 정리 → 해결 방법 → **모양·기능·소재**를 고려해 아이디어 스케치(활동지: 기존 제품 조사 / 디자인 아이디어 / 스케치). 교과서 예 「이동하는 책상」: 수납 부족 → 책·학용품 넣을 공간 / 이동 불편 → 책상·의자 일체형 + 바퀴 / 첨단 → 윗면 디지털 화면·각도 조절·닳지 않는 소재의 바퀴 [교과서 p.56][지도서 §생각펼치기2 ❸, §활동지]
17. ★ **모형 제작하기** — 재료·제작 순서 계획 → 제작. 재료로 성질 표현(투명 필름 = 화면, 지점토 = 폭신함, 모루 = 높이 조절되는 줄기). **좋은 디자인은 한 번에 완성되지 않고 만드는 과정에서 여러 번 수정된다**. 발상이 어려우면 마인드맵 연상 기법 [지도서 §생각펼치기2 ❹·유의점] [6미02-04]
18. 학생 작품 4: 이동하는 책상 / 옷이 피었습니다(옷걸이 줄기를 모루로 → 사용자 키에 맞게 높이 조절) / 반려동물과 행복하게(반려동물이 쉴 공간 있는 소파) / 더위 두렵지 않아(교실의 선풍기+시계 결합 → 손목시계 선풍기) [교과서 p.57][지도서 §작품 학생 작품 설명]
19. ★ **전람회 열기** — 계획서(제품·제품명·전시 내용(모형·홍보 자료)·홍보 방법(포스터·웹툰·체험 유도)·역할 나누기(홍보 자료·공간 꾸미기·상품 전시·안내·사진 촬영)) → 공간 구성(책상 이어 붙여 천·전지 깔아 진열대, 종류별 분류·주제어 벽 부착) → 관람 모둠 / 진행 모둠 교대. **배려가 필요한 학습자**가 참여할 수 있게 안내·시연 역할을 미리 계획 [교과서 p.57][지도서 §생각펼치기2 ❺·지도 길잡이] [6미03-03]
20. ★ **돌아보기** — 우리 모둠이 잘한 점·아쉬운 점(예: 포스터로 아이디어를 잘 전달 / 부스 방문 유도 못 함) + **디자인의 요소를 생각하며** 다른 모둠 제품 칭찬(예: 고양이 공간 의자 → 보기에도 아름답고 기능성도 좋다 / 선풍기 손목시계 → 어디서든 시원해 편리) [교과서 p.57][지도서 §생각펼치기2 ❺] [6미03-04, 6미02-04]
21. ★ 자기 평가 관점: **발상**(디자인 과정에 맞게 창의적으로 계획·제작) / **표현**(제품의 목적에 맞게; **사용하는 데 불편한 점을 줄이려고 노력**; 창의적이고 아름답게) / **태도**(계획·제작에 적극 참여). 동료 평가: 다른 모둠 작품 하나 — 작품명·잘한 점·아쉬운 점 [지도서 §평가지]
22. ★ 확인하기 3항목: 제품 디자인의 요소와 과정을 이해했다 / 문제점을 개선해 제품을 디자인했다 / 전람회를 계획하고 실행하는 과정에 적극 참여했다 [교과서 p.57]
23. 정리: 자리 정돈, 자투리 종이는 재사용하도록 보관. 온라인 수업 시 개인 활동, 재료 없으면 제품 설명서·계획서 제출로 대체 [지도서 §생각펼치기2 마무리·온라인 수업 길잡이]

## 교수·학습 유의사항

- 최대한 다양한 제품을 찾아보게 해서 요소를 **제품에서** 탐색하게 한다 [지도서 §생각펼치기1 유의점]
- 사례집 틀은 선택한 제품들과 어울리는 형과 색으로 [같은 곳]
- 아이디어 발상이 어려운 학생: 마인드맵 연상 기법 안내 [지도서 §생각펼치기2 유의점]
- 좋은 디자인은 한 번에 완성되지 않는다. 과정에서 여러 번 수정될 수 있음을 알게 한다 [같은 곳]
- 이전 활동의 요소를 고려해 디자인하게 한다 [같은 곳]
- 전람회에서 서로의 의견을 존중·배려 [같은 곳]
- 불편함 찾기 어려운 모둠: 불편함 소재 기사 제공 [지도서 §생각펼치기2 지도 길잡이]
- 배려가 필요한 학습자: 안내·시연 역할 미리 계획 [같은 곳]
- 제품 이미지 그리기 어려우면 디자인 인쇄본 제공 [지도서 §생각펼치기1 선택]
- 두 화장실 비교는 허용적 분위기에서 자유롭게 [지도서 §마음열기 유의점]
- 디자인 교육의 핵심은 **디자인적 사고의 기회**: 생각 표현·의사소통·시행착오 [지도서 §배경지식]

### 지도서 평가지 — [6미02-01] 기준 [지도서 §평가지]

| 범주 | 상 | 중 | 하 |
| --- | --- | --- | --- |
| 지식·이해 | 디자인 과정과 요소를 생각해 표현 주제와 발상 방법을 **구체적으로** 말한다 | 말한다 | 일부 말한다 |
| 과정·기능 | 다양한 발상 방법으로 **편리하고 아름다우며 목적에 맞는** 제품을 디자인·제작 | 목적에 맞는 제품을 디자인·제작 | 교사 도움으로 |

피드백(상): 디자인 과정에서 필요성·요소를 알게 하고, 교사·친구 피드백으로 제품 보완 활동 제안. (중): 요소를 고려해 수정·보완할 점을 말하게. (하): 불편에서 문제를 찾아 디자인이 필요함을 알게.

평가 유의점: 결과뿐 아니라 **관찰 태도, 느낌·생각을 구체화하려는 노력**. 자신·친구 작품의 잘된 부분·보완할 부분을 **제품에 담긴 디자인 요소와 관련지어** 볼 수 있는지.
