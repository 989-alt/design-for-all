## 4. 제품 미리보기 레이어 (PRD 초안 60 → 36 + 타일 10)

레이어 방식(02 결정, T02·T05 입력): **형태 = 전체 제품 그림 4장**(중립 회색), **기능 A·B = 작은 부품 그림 4장씩**을 코드가 형태별 앵커 좌표(JSON)에 얹는다. **소재·색 = 질감 타일을 형태 그림의 알파 마스크로 잘라 `multiply` 로 겹친다**(CSS `mask-image` + 타일 PNG — hue-rotate 같은 필터는 쓰지 않는다. PRD "별도 레이어" 의도는 유지하되 형태 4종마다 색 4장을 따로 그리는 48장은 피했다). 단색 옵션(회색·밝은 상판·벽과 같은 색·뚜렷한 색)은 토큰 색 fill. 표시(번호표·이름판) 부품은 **빈 판**이고 번호·글자는 코드가 얹는다.
